Shortcuts & how it works

Tools

  • V Select · M Machine · W Wall · R Room · E Route · Z Zone · T Text · K Measure · G Run path · H Pan

Drawing

  • Machine — pick one of your types, then drag a box. A plain click drops that type's default size. With no type selected you get a plain box you can name yourself.
  • Machine types — the palette starts empty; + New defines a type (name, default size, colour), and clicking the pencil edits or deletes one. Machines keep their own size and colour, so editing a type only changes what you place next unless you tick apply to existing.
  • Wall — click for each corner, Enter or double-click to finish, Esc to cancel. Hold Shift to lock to 45°.
  • Route — drag from one machine to another for a one-way arrow, or click the source then the target. Click empty space to add a bend; double-click, Enter or right-click ends a route anywhere, machine or not. Routes stay attached when machines move.
  • Cascade — select machines and use the cascade panel to repeat them into a line, optionally wired up with routes.

Naming machines

  • Double-click a machine on the canvas — or select it and press Enter or F2 — and type the name in place.
  • Or select it and edit Name at the top of the Properties panel.
  • Select several machines and use Name all to number a whole run at once: typing Press gives Press 1, Press 2, Press 3… ordered left to right.

Writing the process

  • Switch the right-hand panel to Process and press + Step for each step, in order. Every step has a title and a details box for as much as you want to write.
  • From selection adds a step already linked to whatever machine is selected.
  • A linked step's number appears on that machine in the layout; click the number in the step to jump to it, and the ✕ on the chip unlinks it.
  • Reorder with ↑ ↓, copy a step with ⧉, remove it with ✕. Use ↔ in the panel header to widen the panel for writing.
  • Steps are saved inside the layout file. Export writes them out as a Markdown document.

Machine details & zone process

  • Process → Machine details holds per-machine settings — wash pressure, temperature, cycle time, tooling. Add as many rows as you like per machine.
  • Process → Zone process is what each zone does and when, plus the minutes it takes. The panel totals the time across every zone.
  • The three Process sections fold open and shut independently, so you can keep just the one you are working in.
  • Specs and Times in the toolbar show those on the layout itself — details under each machine, cycle times on each zone.

Layers

  • The Layers tab lists everything, top of the stack first. Click a row to select it. ⤒ brings it right to the front and ⤓ sends it right to the back; ↑ ↓ move it a single step.
  • The same four are in the Properties panel as To front / Forward / Back / To back, and work on a whole selection at once, keeping its internal order.
  • The padlock stops an item being selected or dragged on the canvas — handy once the walls and zones are where you want them.
  • The eye takes an item off the canvas entirely. Show all brings the hidden ones back.

Animated run

  • The Run tab animates a part through the plant. Draw path (G) lets you click the exact route — machines to visit, empty space for a corner — and Build from routes follows your arrows instead. Add selected appends a machine.
  • Drag a hand-placed point on the canvas to nudge the path while the Run tab is open.
  • Driven by puts one of your vehicles on the path. Mark a machine type — or a single machine — as a vehicle and it becomes an EV, AGV or forklift: drawn with a dashed outline and a nose chevron, and it drives the path facing the way it travels. It stays parked until you press play, and Restart brings it home.
  • Reorder stops with ↑ ↓, drop one with ✕, and set the seconds of work at each stop. Between stops the token travels the route you drew, or a straight line where there isn't one.
  • P plays and pauses; drag the scrubber to move through the run; Speed is the travel speed in metres per second.

Printing

  • Print (or Ctrl+P) prints the drawing on its own — no toolbars, no side panels.
  • Tick Machine details and Zone process & times to include them, independently of what is showing on screen. Names and Grid are separate switches.
  • Summary tables adds a second page listing every zone with its process and time (and a total), plus every machine's settings.
  • Pick the paper size — A4, A3, Letter or Ledger — and the orientation. Bigger paper means a bigger scale, so more fits inside the boxes.
  • The drawing is scaled to the paper, so labels and detail cards come out the same readable size whatever the plant measures — the preview shows exactly what you will get, and the note gives the scale.
  • A machine too small to hold its name gets the name in a chip just outside the box instead of a truncated one, and names that would collide are dropped rather than drawn over each other.
  • Choose “Save as PDF” in your browser's print dialog to get a file instead.

Room to work

  • \ or the ⛶ button is focus mode — both side panels get out of the way and the canvas fills the window.
  • The second button asks the browser for real full screen.
  • ↔ beside the tabs widens the right-hand panel when you are writing.

Editing

  • Ctrl+Z / Ctrl+Shift+Z Undo · Redo
  • Ctrl+C / Ctrl+V / Ctrl+D Copy · Paste · Duplicate
  • Ctrl+A Select all · Delete Remove · Esc Deselect
  • Arrow keys nudge (hold Shift for 1 m steps)
  • Shift+click to add to the selection · drag on empty space to marquee-select
  • [ / ] send backward / bring forward one step · { / } send to back / bring to front

Navigating

  • Scroll to zoom, middle-drag or hold Space to pan, F to fit everything on screen
  • Hold Alt while dragging to bypass grid snapping
